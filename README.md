# TG — Sistema web para laboratórios de patologia veterinária

Trabalho de Graduação — FATEC Indaiatuba, Análise e Desenvolvimento de Sistemas.

Plataforma web para gestão do fluxo completo de trabalho em laboratórios de patologia veterinária, da solicitação ao laudo.

## Stack

- Frontend: Angular
- Backend: .NET / C# (API REST)
- Banco: SQL Server (Azure SQL)
- IA: Google Gemini API (multimodal)
- Hospedagem: Azure

## Estrutura

```
frontend/   → aplicação Angular
backend/    → API .NET C#
docs/       → documentação e anotações do projeto
```
