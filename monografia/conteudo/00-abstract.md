The growth of the pet market in Brazil has increased the demand for veterinary laboratory tests, but many veterinary pathology laboratories still receive requests through informal channels, such as messaging apps and e-mail, with incomplete information and little traceability. This work aimed to develop a responsive web system to manage the workflow of these laboratories, from the test request to the issuance of the report. The research, of experimental nature, was based on the concepts of laboratory information systems, web applications with client-server architecture, multimodal generative artificial intelligence and veterinary clinical pathology, in addition to the analysis of related academic works and commercial tools. The system, named LabPat, was built with Angular on the frontend, a REST API in .NET organized according to clean architecture on the backend, and a SQL Server database. It serves multiple laboratories with data isolated from each other, with invitation-based registration, links between veterinarians and laboratories, inventory control integrated with test types, PDF reports signed by the technical manager, and public tracking of the test status by code, which exposes only minimal data, in compliance with the Brazilian General Data Protection Law. The integration with the Google Gemini API made it possible to create requests from a photo, PDF or audio of the request form. In the final version, all 52 steps of the functional test script, automated in the browser, passed and, in 15 extractions performed with a fictitious request form in the three formats, all 16 fields were filled in correctly every time, with an average time of 6.9 seconds. The user evaluation, through a validation session with a collaborating pathologist and a questionnaire applied to potential users, is in progress. It is concluded that the system met the proposed development objectives and that multimodal input assisted by artificial intelligence is feasible to reduce typing when opening requests, provided that it is accompanied by human review of the extracted data.

Keywords: veterinary pathology; laboratory information system; multimodal artificial intelligence.
